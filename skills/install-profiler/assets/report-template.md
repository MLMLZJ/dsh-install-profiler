## 1. 排查顺序（照着做，别跳步）

| 步 | 查什么 | 命令（可直接粘贴） | 判断 |
|---|---|---|---|
| 1 | 目录和主程序在不在 | `Test-Path '<安装目录>'` `Test-Path '<主程序>'` | 不存在 → 安装不完整 / 被杀软隔离 |
| 2 | 进程在不在、启动多久 | `Get-Process -Name '<进程名>' -EA SilentlyContinue \| Select Id,StartTime,Responding` | 没有 → 起不来；刚启动 → 可能闪退循环 |
| 3 | 最新日志尾部 | `Get-Content '<日志文件>' -Tail 40` | 看错误前后 20 行，不要只看最后一行 |
| 4 | 24h 崩溃/服务事件 | `Get-WinEvent -FilterHashtable @{LogName='Application';StartTime=(Get-Date).AddHours(-24);Id=1000,1001} -MaxEvents 20` | 有 1000 → 崩溃，记下出错模块 |
| 5 | 服务状态 | `sc.exe qc '<服务名>'` `sc.exe queryex '<服务名>'` | 二进制路径/账户/依赖逐项核对 |
| 6 | 自启动 | `Get-ItemProperty 'HKCU:\...\Run'` | 缺失/被禁用 → 自启失败 |
| 7 | 计划任务 | `schtasks /query /tn '<任务>' /v /fo LIST` | 状态/上次结果 |
| 8 | 端口 | `Get-NetTCPConnection -OwningProcess <PID>` | 端口被占 → 绑定失败 |
| 9 | 配置/注册表 | `Get-Content '<配置>'` / `Get-ItemProperty '<键>'` | 最后才动这里，改前先备份 |

## 2. 症状对照

| 症状 | 先看什么 | 常见原因 | 处置 |
|---|---|---|---|
| 装不上 | 安装日志 / MSI 日志 | 权限 / 残留 / 待重启 / 杀软 | 见第 5 节 |
| 双击没反应 | 进程、事件日志 1000 | 缺运行库 / 被杀软隔离 | 补 VC++/.NET；查隔离区 |
| 启动即闪退 | 日志尾部、WER | 配置损坏 / 版本冲突 | 恢复配置；比对 DLL 版本 |
| 服务起不来 | `sc qc`、系统日志 7000/7009/7031 | 账户权限 / 依赖 / 二进制缺失 | 修账户；启动依赖服务 |
| 升级失败 | 安装日志、磁盘空间 | 旧版本占用 / 更新器缓存损坏 | 清更新器缓存后重试 |
| 磁盘占用异常 | 数据目录、更新器目录 | 缓存/日志堆积 | 清理缓存（先备份配置） |
| 卸载残留 | 卸载项、服务、自启动 | 卸载器未清理 | 手工清理（先备份） |
| 用久了 CPU 高 / 越来越卡 | 连续采样（watch-process.ps1） | 线程泄漏 / 忙等 / 定时器风暴 | 抓 dump 上报；临时计划重启 |
| 内存/句柄持续涨 | 连续采样 | 缓存无上限 / 句柄未释放 | 抓 dump 上报；加阈值告警 |

## 5. 安装失败快速处置

1. 留证据：MSI 用 `msiexec /i <包> /l*v %TEMP%\install.log`；EXE 安装器找厂商安装日志。
2. 看磁盘空间、`PendingFileRenameOperations`、杀软隔离区。
3. 查同产品残留：卸载项、服务、安装目录。
4. 管理员重试一次；仍失败按日志定位，不要反复重装。
